# 样品台账

本地运行的留样质检台账。记录来样登记、多管取样、混合分装、报废和召回，
按微升精确记账（Fraction / Decimal，不经二进制浮点），任何一次操作要么整体
生效，要么整体撤回。

## 启动

```bash
python3 app/server.py            # 默认 http://127.0.0.1:8000
python3 app/server.py --port 8123 --db data/ledger.sqlite3
```

只依赖 Python 3 标准库（SQLite 内建于标准库），不需要安装任何包。打开浏览器后
数据会写入 `data/ledger.sqlite3`，关掉再开继续用。

导出：

- `GET /api/export/inventory` → 库存 CSV
- `GET /api/export/recalls` → 召回清单 CSV

界面右上角也有对应下载按钮。

## 规则要点

- **精确用量**：所有量以 µL 记，收 `1000`、`12.5`、`1/3` 这类写法。小数按十进制
  字面值转成 `Fraction`，所以 `0.1 + 0.2` 精确等于 `0.3`；来源摊分可以是分数，
  中间不取整，界面用 "1/3" 或百分数展示。
- **总量守恒**：一次取样 / 分装必须满足「取样合计 = 分装合计」，否则整次拒绝。
- **完全混匀摊分**：一次操作取多管、出一支成品时，成品组成 = 各来源取样量占本次
  取样总量的比例。同一操作分出多支成品，每支按同样比例摊；历史详情里会逐支列出
  “该成品从每支来源管实际取了多少”。
- **整次原子**：先做完全部校验（编号冲突、来源存在、召回状态、用量是否足够、
  总量是否守恒）再写库，整个写库过程包在一个 SQLite 事务里。中途任何失败都回滚，
  不会出现“原管扣了量、新管没建出来”的半截状态。
- **状态**：管的状态按剩余量实时计算，四种——可用 / 已用尽（剩余 0）/
  已报废（有报废记录）/ 召回中（在库且含被召回批次，禁取样）。已用尽、已报废
  和召回中的管都不能再取样。
- **召回**：按来样批次发起。只标记发起时**仍在库且含该批来样**的管，其他管、
  其他批次照常使用。召回记录永久保存发起时的受影响清单、当时剩余量和当时组成；
  之后这些管被取用或报废，记录里的“当时”数值不变，同时会附上该管的当前状态。
- **冲销**：分装录错可整批冲销。先预览影响再确认：
  - 级联作废：该笔分装、以及取样来源直接或间接用到它所建管的后续分装，全部
    整单作废；被波及管上的报废明细一并作废（同一报废单里的其他管照常报废）；
    被作废分装所建的管视为从未存在（编号保留，不再分配）。
  - 用量退回：被作废分装从**仍有效的原管**误扣的用量退回原管（已用尽的可恢复
    可用）；被作废链条内部的倒手不退，避免重复；原管已报废则整笔冲销拒绝执行。
  - 已发召回继续有效：召回记录不动，退回召回管的量依然禁止取样。
  - 确认令牌：预览会签发一枚令牌，提交时重新计算比对——预览之后相关库存若有
    变动（新取样、新报废、新召回波及相关管），令牌失效，必须重新预览确认；
    无关操作不影响令牌。同一操作只能冲销一次，重复提交不会重复退回。
  - 冲销以一笔 `reverse` 操作记账，原操作保留并标注“已冲销”；按操作序号回看
    仍能看到冲销前的账。
- **追溯**：
  - 按管：来源链（这管由哪些管按多少量混合而来）、当前组成（精确保留到每支来样）、
    去向（被取用到哪些操作和成品）。
  - 按批次：这批来样登记了哪几支管、流向哪些管（含经过多次混合的管）、
    每支管里这批来样占多少、折合当时多少 µL、现在剩多少；已用尽和已报废的也列出。
- **历史库存**：每个操作有自增的登记序号。`?seq=N` 可回看第 N 次操作完成时的
  库存与组成；管的 `created_op` 之后的操作对它不生效。历史操作按登记先后列出，
  并保留每支成品的逐来源摊分。
- **持久化**：SQLite（WAL 模式），关掉进程再打开数据仍在。

## 概念

| 名词 | 含义 |
| --- | --- |
| 来样管（intake） | 登记的一支原始样品，绑定一个来样批次，组成为它自身 100% |
| 分装 / 混合管（pooled） | 由取样/分装操作新建的管，没有自己的批次，组成是各来样按比例 |
| 操作（operation） | 一次登记：来样 / 取样分装 / 报废 / 召回 / 冲销，序号即 `seq` |
| 组成（composition） | 从该管当前内容物可追溯到每支来样管的比例（精确分数） |

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/intake` | `{code, batch, volume, note?}` 登记来样 |
| POST | `/api/split` | `{inputs:[{tube,amount}], outputs:[{code,amount}], note?}` |
| POST | `/api/retire` | `{tubes:[code], note?}` |
| POST | `/api/recall` | `{batch, note?}` |
| GET | `/api/reverse/preview?op=` | 预览冲销影响，返回确认令牌 |
| POST | `/api/reverse` | `{op, token, note?}` 整批冲销一笔分装及依赖它的后续操作 |
| GET | `/api/inventory?seq=` | 库存（可指定历史序号） |
| GET | `/api/history?limit=` | 操作历史 |
| GET | `/api/operation?id=` | 单个操作详情（含逐成品来源摊分） |
| GET | `/api/tube?code=&seq=` | 按管追溯 |
| GET | `/api/batch?batch=&seq=` | 按来样批次追溯 |
| GET | `/api/recalls` / `/api/recall?id=` | 召回记录 |
| GET | `/api/export/inventory` / `/api/export/recalls` | CSV 导出 |

错误统一返回 `{"error": "...", "details": ["..."]}`，明细逐条说明是哪个字段 /
哪支管出的问题。

python3 -I -m unittest discover -s tests -v

回滚、嵌套混合组成、逐成品来源摊分、用尽/报废/召回拦截、召回当时快照、
历史序号回看、重开数据仍在、CSV 转义，以及冲销（级联作废、退回原管、
报废明细部分作废、召回管退回仍禁取、预览令牌失效与重确认、重复提交不多退、
写库故障回滚、v1 数据库迁移）。
